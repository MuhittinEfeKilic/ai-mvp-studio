1) Orchestrator Agent
		Bu sistemin beyni. Bu agent kod yazmak zorunda değil. Daha çok yönetici gibi davranmalı.
	Görevi
		tüm süreci yönetir
		hangi agent’ın ne zaman çalışacağını belirler
		çıktıları toplar
		gerektiğinde agent’ları yeniden çalıştırır
		görev bağımlılıklarını takip eder
	Girdi
		kullanıcının ürün fikri
		kullanıcı tercihleri
		önceki agent çıktıları
	Çıktı
	görev planı
	agent assignment
	workflow state
2) Product Manager Agent
		Bu agent fikirden ürün çıkarır. Bu agent çok kritik çünkü sistemin geri kalanındaki kalite büyük ölçüde buna bağlı olur.
	Görevi
		kullanıcı fikrini analiz eder
		hedef kullanıcıyı belirler
		problemi tanımlar
		MVP kapsamını çıkarır
		feature list üretir
		“şimdilik yapılmayacaklar” listesini hazırlar
		acceptance criteria üretir
	Ürettiği şeyler
		product_spec.md
		mvp_scope.json
		user_stories.md
		acceptance_criteria.md
		Örnek çıktı başlıkları
		Problem
		Hedef kullanıcı
		Değer önerisi
		MVP özellikleri
		V2’ye bırakılanlar
		Başarı kriterleri
3) Solution Architect Agent

Bu agent teknik kararları verir.

Görevi
uygun teknoloji stack önerir
sistem mimarisini kurar
frontend/backend/db ilişkisini tanımlar
klasör yapısını belirler
entity ve API taslağı çıkarır
modüler yapıyı oluşturur
Ürettiği şeyler
architecture.md
tech_stack.md
api_contract.yaml
database_schema.sql veya schema.md
monorepo_structure.md
Karar örnekleri
Next.js mi Flutter mı?
.NET mi Node.js mi Python mı?
PostgreSQL mi MongoDB mi?
auth gerekli mi?
Docker gerekli mi?
tek repo mu monorepo mu?

Bu agent PM agent’ın scope’una sadık kalmalı. Kendi kafasına göre sistemi büyütmemeli.

6) QA / Reviewer Agent

Bu agent kalite kontrol yapar.

Görevi
üretilen kodu inceler
eksik feature var mı kontrol eder
acceptance criteria ile karşılaştırır
test üretir
bug ve risk listesi çıkarır
agent’lara düzeltme görevi yollar
Ürettiği şeyler
qa_report.md
bug_list.md
test_plan.md
fix_tasks.json
Kontrol ettiği şeyler
feature gerçekten çalışıyor mu
endpoint isimleri tutarlı mı
frontend backend contract uyuyor mu
auth akışı bozuk mu
boş state/hata state var mı
MVP dışına taşılmış mı

Bu agent olmadan sistem dağılır.
